# 바른골프피팅센터 동래점 홈페이지

설치 없이 index.html을 여는 정적 홈페이지입니다. 기존 매장 사진·이토보리 글·지도 링크를 유지하며 기획안의 데이터 중심 소개와 첫 화면 예약 폼을 반영했습니다.

## 반영 내용
- 어두운 스튜디오 디자인, QED·FlightScope 소개, 전화 CTA
- 이름·전화번호·날짜·시간, 피팅 품목 복수 선택, 클럽 스펙·고민·전달사항
- 한국 시간 기준 과거 일시 제외, 평일 11:00~20:00 / 주말 11:00~18:00 내 30분 단위 시작 시간 (마감 시각 제외)
- 기존 사진 갤러리·작업 사례·무료 주차·지도와 반응형 레이아웃

## 예약과 카카오 연동 상태
현재 온라인 신청 전송, 예약 가능 슬롯 조회, 알림톡·SMS 발송 서버는 없습니다. 폼 제출은 내용을 클립보드에 복사하며, 실패하면 직접 복사할 텍스트를 표시합니다. 개인정보는 서버에 전송하거나 브라우저에 영구 저장하지 않습니다. 방문자는 전화로 예약을 확인합니다.

제공된 관리자 URL의 채널 ID _BxaZVn을 사용하여 고객용 상담 주소 https://pf.kakao.com/_BxaZVn/chat 을 config.js에 설정했습니다. 우측 하단 카카오톡 1:1 상담 버튼으로 이동하여 복사한 예약 내용을 직접 전송합니다. 실제 채팅 연결은 운영 채널에서 확인해야 합니다. 공식 pf.kakao.com HTTPS 주소만 허용합니다.

실제 예약 접수에는 별도 서버, 예약 저장 및 중복 방지, 개인정보 수집 동의·보관 정책, 관리자 인증이 필요합니다. 알림톡·SMS는 서버에서 알리고 등 발송 대행 서비스의 인증 정보와 승인된 템플릿을 사용해야 합니다. API 비밀키를 config.js에 넣지 마세요.

스윙 영상과 실제 고객의 전후 데이터·후기는 제공되지 않아 임의로 추가하지 않았습니다. 제공된 매장 사진과 기존 피팅 사례를 사용합니다.
